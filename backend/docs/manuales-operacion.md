# Manuales de operación

## Guardia

1. Iniciar sesión con correo y contraseña asignados.
2. En Inicio, presionar **Iniciar turno** y confirmar que aparezca el estado activo.
3. Abrir **Escanear QR**, pulsar **Activar cámara** y encuadrar la credencial. El lector tramita el ingreso.
4. Esperar el resultado visible. Si aparece «Entrada autorizada», comprobar el nombre. Si aparece un rechazo, revisar el motivo.
5. Consultar **Historial** para revisar las validaciones realizadas durante el turno.
6. Presionar **Finalizar turno** al terminar. Después de eso no se permiten nuevas validaciones.

## Administrador

1. Iniciar sesión con una cuenta administrativa.
2. Abrir **Usuarios** para consultar o crear cuentas, activar o desactivar una cuenta vinculada y ver la credencial de un estudiante.
3. Abrir **Historial**, aplicar los filtros disponibles y descargar la página visible en CSV o PDF.
4. Revisar el historial de turnos de guardias, incluidos accesos aprobados y rechazados.

## Estudiante

1. Iniciar sesión con el correo y la contraseña de la cuenta vinculada.
2. Abrir **Mi código QR** y presentar la credencial visible al guardia.
3. Mantener el portal conectado para que actualice el código después de usarlo o al vencer.

## Incidentes

Si el lector indica «Sin confirmación del servidor», consultar el historial antes de repetir el escaneo. Si indica que el ingreso se registró con auditoría pendiente, evitar repetirlo e informar al administrador. Ante indisponibilidad, aplicar el procedimiento de contingencia autorizado en portería y conservar el registro para su conciliación.
